# K.O.C Collections

The public storefront for K.O.C Collections. This repository contains the static HTML pages and image assets used by the website.

## Run locally

Open `index.html` in a browser, or serve this folder with any static web server.

## Publish with GitHub Pages

In the repository settings, enable GitHub Pages for the `main` branch and the root folder. The storefront will be available at the Pages URL shown by GitHub.

Private admin and server files are intentionally excluded from this public storefront repository.
